PicoPlayer — просмотр фото, видео и музыки

КАК ЗАПУСТИТЬ
  Дважды щёлкните «Запустить PicoPlayer.bat».
  При первом запуске он сам установит нужную библиотеку (нужен интернет).
  Если Python не установлен — откроется сайт python.org. При установке
  отметьте галочку «Add Python to PATH», потом снова запустите .bat.

«ОТКРЫТЬ С ПОМОЩЬЮ» И ПРАВАЯ КНОПКА МЫШИ
  Один раз запустите «Добавить в Открыть с помощью.bat».
  После этого:
  • правая кнопка по фото/видео → «Открыть в PicoPlayer»
    (в Windows 11 — сначала «Показать дополнительные параметры»);
  • правая кнопка → «Открыть с помощью» → PicoPlayer;
  • чтобы файлы всегда открывались в PicoPlayer: «Открыть с помощью» →
    «Выбрать другое приложение» → PicoPlayer → «Всегда».
  Если перенесёте папку с плеером — запустите установщик ещё раз.
  Убрать: «Убрать из Открыть с помощью.bat».

КАК ОТКРЫТЬ ФАЙЛЫ
  • Перетащите фото/видео/папку на «Запустить PicoPlayer.bat» или в окно плеера.
  • Или кнопки «Открыть» / «Папка».
  • Открыли один файл — в списке справа сразу вся его папка.

БОЛЬШИЕ КНОПКИ
  Поведите мышкой над фото или видео — появятся большие кнопки:
  в центре «Пуск/Пауза», по бокам «Назад» и «Вперёд».
  Через 2 секунды без движения мыши они сами прячутся.

ГЛАВНЫЕ КЛАВИШИ
  ← →          предыдущий / следующий файл
  Пробел       пауза
  ↑ ↓          громкость
  F или Enter  во весь экран, Esc — выйти
  + − 0        масштаб фото, 0 — по размеру окна
  R            повернуть фото
  C            сравнить 2 фото на одном экране (Ctrl+2 — выбрать второе)
  S            слайд-шоу
  Delete       удалить в Корзину
  F1           все горячие клавиши

ЕСЛИ ЧТО-ТО НЕ ТАК
  Ошибки записываются в файл picoplayer_error.log в этой папке.
